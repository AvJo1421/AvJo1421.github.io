Ingredient Analysis using NLP

Grading and answering questions about food ingredients

What it does

Most shoppers choose food by packaging or brand, rarely reading the ingredients, and fewer still can interpret them. This project uses NLP to read a product's ingredient list, grade it on a simple health scale, and let users ask plain-language questions about what is inside and how healthy it is.

More details

How it works

🏷️
Custom Named Entity Recognition

A domain-specific Custom NER model, trained in Azure AI Foundry's Language Studio, identifies and classifies food ingredients from raw ingredient text.

⚖️
Rule-based grading

A rules layer maps recognised ingredients onto a five-tier health scale (Grade A to E), with an Unknown tier for products the model cannot fully resolve.

🤖
Batch classifier

A TF-IDF vectoriser and classification model extend the grading to batches of products, turning ingredient text into numerical features for fast, scalable scoring.

💬
Question answering

A Question Answering and Conversational Language Understanding layer lets users ask about a product's ingredients and health in natural language and get direct answers.

🔗
Orchestrated pipeline

An orchestration layer chains the stages together, so recognition, grading, and answering run as a single end-to-end flow from raw ingredients to a user-facing response.
